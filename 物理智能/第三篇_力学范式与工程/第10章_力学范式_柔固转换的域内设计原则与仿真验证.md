# 第10章 力学范式：柔固转换的域内设计原则与仿真验证

在进入具体的力学域设计原则之前，有必要先建立一套统一的语言来描述SMA相变过程中能量的流动与转换。这套语言并非来自教科书——它是从第8章螺旋迭代的失败经验中"长"出来的，用于解释"为什么SMA能做到这些事"。它将贯穿本章的五条核心设计原则，作为它们共同的能量逻辑。

本章所展开的，正是第8章确立的"柔固转换"（The Flexi-Rigid Transition, FRT）设计方法论在力学域的系统化实现——用SMA相变在柔性态与刚性态之间的可控可逆切换，去完成恒力、吸能、阻尼、顺应等一整套力学功能。

## 10.1 相变势能与手续费模型——力学范式的能量基石

### 10.1.1 相变势能：晶格自带的"弹簧"

SMA有两种晶体结构：奥氏体（高温相）和马氏体（低温相）。每一种结构都有其自身的"内禀稳定性"——由化学自由能度量。化学自由能的公式 G = H − TS，本质上是焓与熵的一场博弈：

- **焓（H）**是能量的量——它总想把系统拉向能量最低的状态。原子结合越紧密，焓越低，系统越"想"停留。
- **熵（S）**是能量的质——它总想把系统推向最混乱的状态。原子振动越剧烈，熵越高，系统越"想"扩散。
- **温度（T）**是熵的放大器——T 与 S 相乘，温度越高，熵的发言权越大。

低温时，熵的发言权很小，焓说了算——能量更低的马氏体（原子结合更紧密）是稳定相。高温时，温度这个放大器让熵有了巨大的发言权——混乱度更高的奥氏体（原子振动更剧烈）反而是稳定相。于是得到SMA最根本的物理剧本：

- **低温时**：焓占主导，马氏体是稳定态（低焓），奥氏体是不稳定态。
- **高温时**：熵占主导，奥氏体是稳定态（高熵），马氏体是不稳定态。

这个博弈的结果，就是相变能够发生——而驱动它的根本力量，正是不同温度下焓与熵对自由能贡献的此消彼长。但这里需要澄清一个容易误解之处：奥氏体的焓值其实高于马氏体——按"焓越低越稳定"的直觉，它似乎"不应该"稳定。高温之所以能扭转局面，正是因为温度这个放大器让熵的优势压过了焓的劣势，使奥氏体在自由能层面重新成为最低点。高焓却稳定，正是热力学在材料中的"阳中有阴"。

把这场博弈浓缩成一句话，就是：**焓是能量的量，它告诉你系统里有多少能量可用；熵是能量的质，它告诉你这些能量有多"好用"。** 低温时可用但不好用，于是熵把稳定权交给了低焓的马氏体；高温时能量充裕、熵占据主导，稳定权又交还给了高熵的奥氏体。在加热逆相变（马氏体→奥氏体）与降温正相变（奥氏体→马氏体）的交替工况下，这条规律驱动材料在两个稳定态之间可逆切换，而切换的方向、温度与迟滞，全部由物理定律自行决定。

这两种结构之间存在一个化学自由能差。这个差值，就是**相变势能**——它不是比喻，是精确的物理描述。

在力学范式中，相变势能扮演的角色是：自动归位的弹力。在A_f以上温度施加外力，强行把稳定的奥氏体转变为不稳定的应力诱发马氏体，外力做的功以相变势能的形式储存在晶格中。外力撤除后，势能释放，驱动材料自动复位。一根SMA丝之所以能"自己弹回来"，不是因为它被编程了，而是因为晶格里存着一笔势能存款。

### 10.1.2 手续费模型：一次超弹性循环的"存钱-取钱"

超弹性循环中的能量收支，可以用一个"存钱-取钱"模型来理解——本书称之为**手续费模型**：

**加载段（存钱）**：推动相界面把奥氏体变成马氏体，需要付出两样东西。

- **存款**：将稳定奥氏体转变为不稳定马氏体所需的"成本"——这笔能量被晶格吸收储存，就是相变势能，占大头。
- **手续费**：推动相界面时，原子层面孪晶界面移动产生的不可逆摩擦——需要额外付出，占小头。
- 加载曲线下方的面积，就是付出的总功。

**卸载段（取钱）**：撤去外力，相变势能释放，驱动马氏体变回奥氏体。同样需要克服界面摩擦——势能释放的总量被摩擦"克扣"了一小部分，剩下的才作为弹性功返还。卸载曲线下方的面积，就是回收的可恢复弹性能。

**最终结算**：

- 加载与卸载曲线重叠的那部分面积，是"存款"——相变势能，一存一取没有消失。
- 加载与卸载曲线之间的回环面积，是"手续费"——真正被消耗掉的、不可逆的能量，即滞回耗散。

于是得到力学范式的能量守恒方程：

**总功（恒力 × 位移）= 存款（相变势能）+ 往返手续费（滞回耗散）**

力学范式关心的，正是那笔"手续费"——它被用来"吃掉"动能、减振吸能、实现冲击防护。每一次超弹性循环，都是一次精准的、原子级别的摩擦制动。这是本书后文所有吸能案例（P2、P3）共同的能量来源。

## 10.2 力学原语：五条原则的物理根

### 10.2.1 从经验原则到力学原语

第8章在螺旋迭代中记录了五条经验性设计原则："丝线恒拉力""点状驱动·周边吸能""缝合但不收紧""八字锚固""温控多级分时变形"。它们是具体场景中的判断标准——好用，但彼此孤立，共享的底层物理未被点名。

本章做的第一件事，是把这五条经验原则还原到它们共同的物理根上。当这些经验按"依赖SMA相变的哪个基本能力"归类时，会发现背后只有四种不可再分的能力单元——本书称之为**力学原语（primitive）**：

1. **刚度切换**：SMA在马氏体（柔性，E ≈ 28–40 GPa）与奥氏体（刚性，E ≈ 62–83 GPa）之间可逆切换，无需任何活动部件。
2. **恒力平台**：在超弹性平台区内（≈6–8%应变），应力几乎不随应变变化。
3. **滞回耗散**：加载-卸载滞回环包围的面积，将机械能不可逆地转化为热。
4. **几何可编程性**：临界相变应力 σ_cr = F_cr/A，改变截面积直接改变力阈值。

四种原语是本章五条原则的物理基础：P1依赖几何可编程性，P2依赖滞回耗散（可选配刚度切换），P3依赖滞回耗散与几何可编程性的组合，P4依赖恒力平台（可选配刚度切换），P5依赖恒力平台。

经验原则与新五条之间的对应关系，可用下表归纳——前者是"发现的现场"，后者是"结构的骨架"：

| 第8章经验原则 | 本章原则 | 对应关系 |
|---|---|---|
| 丝线恒拉力 | P5 恒力顺应 | 同一物理——超弹性平台恒力 |
| 八字锚固 | P2 空间辐向网络 | 同一物理——八点锚固的辐向张拉 |
| 点状驱动·周边吸能 | P2 + P3 组合 | 局部驱动分解为周边多丝分级耗能 |
| 缝合但不收紧 | P5（连接场景） | 恒力顺应用于接口连接 |
| 温控多级分时变形 | §10.3 桥梁原则 | 以温度为时间轴的多级触发 |

### 10.2.2 五条原则的呈现格式

本章按设计复杂度组织五条原则：从最简单的单元件配置到最复杂的多层架构。每条原则的呈现格式统一为：**物理基础**（依赖的力学原语）、**物理机制**（物理特性如何转化为工程设计逻辑）、**设计方程**（适用时的定量关系）、**设计指南**（工程实现建议）、**实现模式**（同一原则的不同配置路径）、**应用场景**（典型领域）、**变种**（跨场景演化）、**跨域扩展**（对偶到其他物理域）。

### P1 变截面梯度力控

**域**：力控制

**物理基础**：几何可编程性——σ_cr = F_cr/A，改变截面积直接改变力阈值

**物理机制**：当SMA元件沿受力方向具有变化的截面积时，薄截面段在较低的力值下先达到临界应力、进入超弹性平台；厚截面段在更大的力值下才进入平台。随着力增加，各段依次进入平台，产生阶梯状的力-位移曲线。以两段式变截面丝材为例：薄段面积A₁在力F₁ = σ_cr × A₁时进入平台；厚段面积A₂在力F₂ = σ_cr × A₂时进入平台。两段平台的力之比精确等于面积之比。

**设计方程**：

F_plat,i / F_plat,j = A_i / A_j

平台力的步进比精确等于面积比——纯粹的几何编程。步数等于不同截面积的数量；步宽由段长和局部应变分布决定。

**设计指南**：在SMA丝材特定位置局部蚀刻以减小截面积。较薄段先进入平台（先出力），较厚段后进入平台（后出力）。

- 串联配置：薄段必须足够长以防止过应变。当厚段进入平台伸长ΔL₂ = ε_L·L₂时，薄段承受额外应变ΔL₂/L₁。为保持弹性（<1–2%），需满足L₁/L₂ > 3–6。
- 并联配置：每根丝独立承载相同位移——薄丝的行程必须覆盖全设计位移范围。

**实现模式**：

- 模式I（串联变截面）：单根丝沿长度方向分段设置不同截面积，各段依次进入平台。
- 模式II（数量增减）：多根同规格丝并联，增减丝数改变总平台力（N × F_single）。
- 模式III（异径并联）：不同直径的丝并联，各自贡献不同平台力，叠加输出。

**应用场景**：骨折外固定夹板（模式II，急性期2–3根→恢复期6根→塑形期9根）、多级夹持接口、顺序展开机构（模式I）。

**变种**：

- 串联变截面——沿单根丝长度方向蚀刻出多个不同直径段，产生多个力台阶。
- 数量增减——通过增减并联丝数量调节总力值，步进为单丝平台力的整数倍。
- 异径并联——不同直径丝并联，细丝先出力（低阈值），粗丝后介入（高阈值）。

**跨域扩展**：该原则不限于力学域。变截面设计同样适用于流体域（变截面流道产生多级压降）和热学域（变截面导热路径产生多级热阻）。本书第4章的跨域功能对偶性映射表正是这一扩展的形式化表达。

**仿真验证位置**：§10.4（Liang-Rogers定量验证，力比=面积比）

### P2 空间辐向网络

**域**：能量耗散、运动学

**物理基础**：滞回能量耗散（即8.1节介绍的"手续费"——超弹性循环中滞回环面积将冲击动能转化为热能）；可选配刚度切换能力

**物理机制**：SMA丝以辐向模式布置，从中心点（或环）向外辐射形成张力网络。任何方向的冲击在到达被保护物之前，会被分解为多根SMA丝的轴向拉伸——无论冲击来自哪个方向，SMA丝始终工作在最优的轴向拉伸模式。冲击结束后，所有丝协同回弹，将被保护物复位至中心。

**辐向网络的上限——最小完备集**：三维空间中，从中心到八个角点的辐向锚固是在对称箱体锚固框架下覆盖所有方向的最小完备配置。四点或六点锚固存在方向盲区；八点锚固消除了所有盲区。这是拓扑意义上的"最小完备"——少于八个，就有方向无法被有效分解为轴向拉伸。**但须限定"最小完备"的确切含义：**八个角点的方向是四条体对角线 (±1,±1,±1)，与坐标轴方向 (1,0,0) 等的夹角恒为 **54.7°**——**不存在与任意冲击方向"共线"的丝**。任意方向之所以能被覆盖，靠的是八条丝（自平衡张拉整体）的**分力合成**（八条体对角线构成 R³ 的正张成集），而非某根丝与之共线拉伸。故"最小完备"的准确表述是"**在对称箱体＋刚性锚点假设下，八点构成拓扑意义的最小有效张拉覆盖**"，而非"每个方向都有一根丝正对着它"。

**设计指南**：至少部署8根SMA丝以覆盖半球空间。中心锚点连接被保护部件；丝的外端锚固于刚性框架。准静态加载下，冲击能通过SMA超弹性滞回耗散；动态加载下，网络提供多路径冗余——单丝失效，其余丝继续工作。

**应用场景**：冲击防护容器（八锚点三维辐向）、防震手套（五节点二维降维）、头盔衬里、运动护具。

**变种**：

- 三维辐向网络（八锚点）——八个角部锚点，拉力汇聚于几何中心，任意方向冲击分解为轴向拉伸。
- 二维辐向网络（多点）——平面内的多点辐向布局，适用于防护面积大于厚度的场景（如背部护板）。
- 蜂窝拓扑扩展——从点约束到面约束的拓扑演化（详见力学域工程案例章节的蜂窝案例）：SMA丝网络编织成空间填充多面体胞元——四面体、八面体、截角二十面体——每个胞元面都是一个SMA丝环，从任何方向受压时都进入超弹性弯曲，各向同性由构造本身保证，不依赖取向。

**仿真验证位置**：§10.4.5（待验证议程）

### P3 分级阻尼

**域**：能量耗散

**物理基础**：滞回能量耗散（手续费）与几何可编程性的组合——不同截面积的丝在不同力幅值下依次进入超弹性滞回

**物理机制**：不同直径的SMA丝在不同力/应力幅值下进入超弹性滞回。细丝在低激励幅值下开始耗能（小截面积在较低力下达到σ_cr）；粗丝仅在高幅值下激活。通过并联布置不同直径的丝，创建一个无源的、分级的能量耗散系统，在宽激励幅值范围内提供有效阻尼。

**设计指南**：将SMA丝分为三级——细(d₁)、中(d₂)、粗(d₃)。第k级的触发力为F_cr,k = σ_cr × π(d_k/2)²。d₂/d₁ ≈ 1.5–2.0提供清晰的激活分离。总丝数由目标阻尼力除以单丝平台力决定。

直拉丝受限于6–8%应变行程。弯曲或预弯SMA构型（C形弓、螺旋弹簧、椭圆弧、菱形网）将相同局部应变转化为更大的全局位移，适用于空间受限的分级阻尼。（弯曲为何比拉伸"赚"行程、以及SMA拉压不对称的通俗解释，见P4。）

**应用场景**：帕金森震颤护腕（粗细丝分级恒力负载，菱形网编织带——两层相反取向的编织网，∅0.08–0.15mm丝，将关节旋转分散到数十个节点，保持每个节点在1–3%弯曲应变内；机制是恒力负载改变手部动力学响应、破坏震颤共振条件，详见第12章案例三）、航天器章动阻尼器（球形蜂窝）、多模式振动隔离、建筑抗震加固。

**变种**：

- 粗细丝并联——细丝先响应小幅振动，粗丝在大幅冲击时介入。
- 长短错落弯曲——改变有效工作长度实现分级。
- 三维球形蜂窝（C60拓扑）——变密度截角二十面体SMA丝壳，每个方向都有相同的弯曲主导滞回路径，全向阻尼。

**仿真验证位置**：§10.4.5（待验证议程）

### P4 功能-行程解耦

**域**：运动学、接口

**物理基础**：恒力平台——SMA超弹性仅在可恢复应变极限ε_L（NiTi为6–8%）内可靠工作

**物理机制**：SMA超弹性仅在可恢复应变极限ε_L（NiTi为6–8%）内可靠工作。超出此范围，塑性变形累积。本原则将系统解耦为两个协同层：SMA层在有限行程内提供精密力控制（恒力、阻尼或分级力）；解耦层（弹簧、滑动界面、磁阈值机构或材料弹性）提供独立于SMA行程的大范围自由运动。

**设计方程**：

总行程 = min(L_SMA × ε_L，所需精密行程) + L_解耦

其中L_SMA为SMA有效长度，ε_L为最大可恢复应变（≤6–8%），L_解耦为解耦层提供的附加行程。

**设计指南**：分离功能——SMA做精度，解耦层做广度。当应用行程超过SMA的6–8%应变能力时引入解耦层。解耦选项包括：滑动界面（允许大旋转而不改变SMA应变）、磁阈值机构（在预设力下脱开）、弹性顺应（弹簧串联）、以及弯曲构型行程放大（用弯曲变形替代拉伸，将6–8%局部应变转化为毫米级宏观位移——菱形网编织带即为此原理的极致体现；其代价是弯曲刚度远低于拉伸刚度——刚度按几何细长比 L/d 的平方下降（见下文"弯曲为什么比拉伸赚行程"）——即以更小的力换取更大的行程）。

**通俗解释——弯曲为什么比拉伸"赚"行程**（非专业读者可直接读这段，专业读者可跳过）：

一根直丝被拉伸时，整个截面的每一处都在均匀拉长——像橡皮筋整体被抻长，所有部分一起承力，所以行程受限于材料的均匀应变极限（SMA约6–8%）。

把同一根丝弯成弓形或织成网，情况完全不同。想象把一根面条弯成弧形：弯得越狠，弧的外侧被拉得越紧，内侧被压得越紧，中间有一条既不拉也不压的"中性线"。真正"用足了应变"的，只有最外面那一薄层；越靠近中心，应变越小，内侧还是反向受压。

这正是弯曲"赚行程"的秘密：它把应变"摊薄"到表面薄层，内部大部分材料只是轻轻弯过。同样的应变预算（6–8%），拉伸只能产生等比例的位移（δ = ε × L），弯曲却能把同一应变放大——以悬臂构型（一端固定、自由端加载）为例：

δ_弯曲 ≈ (2/3) × (L²/d) × ε，即 行程放大倍数 ≈ (2/3) × (L/d)

这个倍数**只由几何细长比 L/d 决定**，与材料无关。代价也随之给出——弯曲刚度与拉伸刚度之比：

k_拉伸 / k_弯曲 = (16/3) × (L/d)²

以 L/d = 50 的细丝（长 50 mm、径 1 mm 量级）为例：行程放大约 **33 倍**（同样 6% 应变，拉伸给 0.06L，弯曲给约 2L），代价是刚度降到约 **1/13000**。所以"弯曲赚行程"从不免费：**放大多少倍行程，就按几何比的平方丢掉刚度。** L/d 越小越省刚度，但能放大的行程也越少——这正是设计者真正在权衡的那一个数。

SMA弯曲还有一个别的金属没有的细节：拉和压不对称。NiTi受拉时临界应力低、可恢复应变大（6–8%）；受压时临界应力约高1.2–1.6倍、可恢复应变只有约3–5%。所以一根SMA丝弯成弧形时，弧的外侧先进入"拉伸超弹性平台"（力几乎不变），内侧后进入"压缩相变"或始终刚性——弯曲平台的力由两侧共同决定。这也是菱形网每个节点只弯曲1–3%而非6–8%的原因：要给更"脆弱"的压缩侧留足安全余量。

**应用场景**：帕金森震颤护腕（三环滑动架构：内环跟随手腕，外环固定于前臂套，中环在外环槽内滑动——震颤时中环静止，SMA提供恒力负载；大幅自主运动时中环滑动，SMA应变锁定在8%附近）、航天着陆缓冲、假肢装置。

**变种**：

- 滑动界面解耦——SMA应变锁定在安全区间，大行程由滑动界面吸收。
- 磁阈值脱开——超过预设力值时磁力脱开，保护SMA不过载。
- 弹性串联解耦——弹簧与SMA串联，弹簧提供大行程，SMA提供精密力控。
- 弯曲构型行程放大——用弯曲变形替代拉伸，将6–8%局部应变转化为毫米级宏观位移（菱形网编织带）。

**仿真验证位置**：§10.4.5（待验证议程）

### P5 恒力顺应

**域**：力控制、接口

**物理基础**：恒力平台——在超弹性平台区内（≈6–8%应变），应力几乎不随应变变化

**物理机制**：在超弹性平台区内工作的SMA元件，在宽应变范围内（≈6–8%）维持近乎恒定的应力。当SMA接触目标表面时，尽管存在几何变化、肿胀/收缩或磨损，接触力保持稳定。

**设计方程**（简化一维）：

F_接触 ≈ σ_平台(T) × A；dF_接触/dδ ≈ 0（平台应变范围内）

其中σ_平台为相变平台应力，A为SMA截面积，δ为挠度。

**设计指南**：将SMA偏置到平台中点（≈3–4%应变）以最大化双向恒力行程。将A_f设定在预期工作温度范围或略低。对于体温应用，A_f ≈ 32–37°C。

**应用场景**：血管支架、正畸弓丝、恒力电接触、自适应密封、骨科固定钉。

**变种**：

- 直接恒力贴合——SMA直接接触目标表面提供恒力（止鼾器、血管支架）。
- 预拉伸恒力锁定——SMA预拉伸至平台区，通过几何锁止提供恒力夹持（快拆接口）。
- 恒力减张缝合——U形变截面SMA缝线，在不同组织厚度下提供恒定缝合张力。

**仿真验证位置**：§10.4.5（待验证议程）

## 10.3 力学范式的扩展：温控多级分时变形

五条核心设计原则之外，还有一条原则连接着力学范式与热学范式——它本身跨越了两个域，既是力学的（多级力输出），又是热学的（温度作为时间轴）。这条原则是：**温控多级分时变形**。

**定义**：在需要响应环境温度变化自动执行多级功能切换的场景中，集成多种具有不同奥氏体相变结束温度（A_f）的SMA元件，各元件在其预设温度阈值依次发生独立的相变和形状变化，构成一套完全由环境热能驱动的纯物理形态程序。

**物理本质**：用不同相变温度作为触发的时间序列，用不同预设形状作为各阶段的输出。

这条原则在本书框架中的特殊地位在于：它不需要电子代码，不需要传感器，只需要环境温度本身作为"程序计数器"。当温度爬升时，不同A_f的元件依次被激活——A_f最低的先动，A_f最高的最后动。冷却时反向执行。

它是力学范式向热学范式过渡的桥梁。在力学范式中，它是P1（变截面梯度力控）的热学版本——P1用截面变化编程力值的时序，温控多级分时变形用相变温度编程动作的时序。而在热学范式中（详见热学域章节），它是"橙瓣自治网络"和"搏动循环"的底层逻辑——每个橙瓣根据局部温度自主决策，不需要中央控制器告诉它"该你了"。

**应用场景预览**（将在后续工程实证章节展开）：

- 轨道热循环飞轮发电系统：8级A_f梯度拨片（40–75°C，步进5°C），在轨道升降温过程中依次触发，实现无源时序控制。
- 智能热控百叶窗：不同A_f的SMA弹簧在温度爬升过程中依次打开不同角度的百叶窗叶片。
- 多级热开关网络：不同A_f的SMA热开关在温升过程中依次闭合，逐级激活散热通道。

## 10.4 Liang-Rogers变截面仿真验证

本章五条核心原则中，P1（变截面梯度力控）已通过Liang-Rogers一维本构模型完成了定量仿真验证。其余四条原则（P2–P5）的仿真验证将在后续研究中完成，本章末列出待验证议程。

### 10.4.1 方法

采用Liang-Rogers一维本构模型计算应力σ、应变ε和马氏体体积分数ξ作为施加位移的函数。材料参数取自公开发表文献：

| 参数 | 符号 | 数值 |
|---|---|---|
| 奥氏体模量 | E_A | 62 GPa |
| 马氏体模量 | E_M | 28 GPa |
| 最大相变应变 | ε_L | 5.5% |
| 工作温度 | T | 310 K (37°C) |
| 马氏体起始温度 | M_s | 258 K (−15°C) |
| 奥氏体结束温度 | A_f | 293 K (20°C) |
| 应力影响系数 | C_M, C_A | 8 MPa/K |

### 10.4.2 结果

仿真三种构型：

- 构型C1（均匀参考）：∅1.0 mm × 60 mm——产生单一超弹性平台。
- 构型C2（2阶梯度）：∅1.0 mm × 20 mm + ∅1.5 mm × 20 mm，串联——两个离散平台。
- 构型C3（3阶梯度）：∅0.8 mm × 20 mm + ∅1.2 mm × 20 mm + ∅1.6 mm × 20 mm，串联——三个离散平台。

**均匀丝（C1）**：单一超弹性平台在约325 N处起始，对应σ_cr = 325/(π×0.5²) ≈ 414 MPa，与预测值σ_cr = C_M(T − M_s) = 8 × (310−258) = 416 MPa匹配（误差<0.5%）。

**2阶梯度丝（C2）**：两个清晰分离的平台——约326 N（∅1.0 mm段）和约733 N（∅1.5 mm段）。平台力比F₂/F₁ = 733/326 = 2.25，精确匹配截面积比A₂/A₁ = (1.5/1.0)² = 2.25。

**3阶梯度丝（C3）**：三个顺序平台——约208 N（∅0.8 mm）、约469 N（∅1.2 mm）和约834 N（∅1.6 mm）。力比1 : 2.25 : 4.00匹配面积比1 : 2.25 : 4.00。

### 10.4.3 温度敏感性

由于临界相变应力遵循σ_cr(T) = C_M(T − M_s)，所有平台力随温度均匀移动——但力比值保持不变。这是一个关键的实际优势：几何编程提供的力比值在温度变化时保持鲁棒，即使绝对力值随温度变化。

| 温度 | 场景 | σ_cr (MPa) | 平台1 (N) | 平台2 (N) | 比值 F₂/F₁ |
|---|---|---|---|---|---|
| 25°C | 室温/航天冷工况 | 350 | 275 | 619 | 2.25 |
| 37°C | 体温（生物医学） | 434 | 341 | 767 | 2.25 |
| 70°C | 航天热工况/太阳加热 | 665 | 522 | 1175 | 2.25 |

> **表注**：表中σ_cr为各工况下的有效临界应力。对照§10.4.1的标称参数，σ_cr = C_M(T − M_s)在37°C直接给出416 MPa（表值434 MPa），差异约4%，源于表格采用的有效C_M略高于标称8 MPa/K（批次波动）与数据取整；表内平台力均由σ_cr × 截面积计算，力比不变性（F₂/F₁ = 2.25）不受此影响。

设计点周围±5°C温度变化使平台力移动约**±9.2%**（按 σ_cr = C_M·(T−M_s)、C_M = 8 MPa/K：ΔF/F = 8×5/434 ≈ 9.2%；若取标称416 MPa则约9.6%），设计者须在工况温度预算中考虑这一点。

### 10.4.4 与独立实验的对比

上述预测已由Chen et al.（2023）和Meng et al.（2016）的独立实验确认。Chen等人实验展示了2阶NiTi板（3mm→4mm宽度）的顺序应力诱发马氏体相变，平台力比匹配面积比。Meng等人独立确认了局部过时效NiTi丝中的两个离散应力平台。

仿真结果与独立实验数据的偏差小于2%。偏差来源包括：热处理变异性（应力影响系数C_M批次间变化±0.5 MPa/K）、应变率效应（>1 s⁻¹时绝热加热使平台应力升高约12%）、以及几何过渡效应（电化学蚀刻过渡区产生0.5–2mm梯度区域，使力-位移曲线在平台间平滑化但不改变平台力水平本身）。

仿真确认了P1的核心物理定律：多级力输出可通过纯几何截面积变化编程到SMA元件中，力平台比值精确等于截面积比值。

### 10.4.5 待验证议程

P2（空间辐向网络）、P3（分级阻尼）、P4（功能-行程解耦）、P5（恒力顺应）的定量仿真验证——包括不同加载速率下的动态响应、多轴应力状态下的滞回行为、以及循环加载下的性能退化——将在后续研究中完成。初步估算框架如下：

| 原则 | 待验证的核心预测 | 建议的仿真框架 |
|---|---|---|
| P2 | 任意方向冲击下，被激活丝的数量与冲击方向的函数关系 | 多体动力学 + SMA本构耦合 |
| P3 | 不同直径丝的激活时序与阻尼力叠加规律 | 并联SMA丝阵列的时域仿真 |
| P4 | 解耦层介入前后SMA应变锁定效果的定量评估 | 多自由度运动学 + SMA本构 |
| P5 | 不同预应变下接触力波动的幅值范围 | 准静态拉伸-卸载循环仿真 |

## 10.5 原则间关系图与设计空间

五条原则不是孤立的。它们之间存在内在的逻辑关联，构成了力学范式的完整设计空间。

### 10.5.1 原则间的依赖关系

- **P5（恒力顺应）是基础**——它定义了SMA超弹性平台的核心能力：在宽应变范围内维持恒力。其他四条原则都在此基础上扩展。
- **P1（变截面梯度力控）是对P5的时序扩展**——将"恒力"从单一值扩展为"多个恒力按顺序出现"，实现了力的时序编程。
- **P3（分级阻尼）是对P5的幅值扩展**——用不同直径的丝在不同力幅值下提供恒力阻尼，实现了力的幅值分级。
- **P2（空间辐向网络）是对P5的方向扩展**——将单根丝的恒力特性扩展到任意方向，实现了力的方向解耦。
- **P4（功能-行程解耦）是对P5的行程扩展**——将SMA的有限恒力行程与系统的大行程需求分离，实现了力的行程解耦。

### 10.5.2 设计空间矩阵

| 原则 | 核心问题 | 设计变量 | 输出特性 |
|---|---|---|---|
| P5 | 如何在一个点上提供恒力？ | 截面积A、温度T | 单一恒力平台 |
| P1 | 如何让力随时间变化？ | 截面积序列A₁,A₂,… | 多级恒力平台（时序） |
| P3 | 如何让力随幅值变化？ | 直径序列d₁,d₂,… | 多级恒力平台（幅值） |
| P2 | 如何让力随方向变化？ | 锚点位置和数量 | 方向无关的恒力响应 |
| P4 | 如何让力随行程变化？ | 解耦层设计 | 有限行程恒力 + 无限行程自由 |
| 温控多级 | 如何让动作随温度变化？ | A_f序列T₁,T₂,… | 多级形态切换（时序） |

### 10.5.3 设计决策树

面对一个力学设计问题，按以下顺序决策：

1. 是否需要恒力输出？ → 否：考虑其他方案；是：进入P5。
2. 是否需要多个力值按顺序出现？ → 是：P1（变截面梯度力控）。
3. 是否需要不同力值应对不同幅值？ → 是：P3（分级阻尼）。
4. 是否需要应对任意方向的力？ → 是：P2（空间辐向网络）。
5. 是否需要超出6–8%应变的大行程？ → 是：P4（功能-行程解耦）。
6. 是否需要动作随温度自动分时执行？ → 是：温控多级分时变形。

力学范式证明了第4章的论断：计算的基本操作——阈值判断、单向导通、振荡、存储——可以在力学域中用SMA独立实现，不依赖电子。而温控多级分时变形则展示了从力学域向热学域过渡的桥梁——温度作为时间轴，相变温度作为触发时刻表。

## 10.7 本章小结

本章将第8章FRT螺旋迭代方法论中提炼的五条设计原则在力学域中完整展开，并补充了连接力学与热学范式的温控多级分时变形原则。

- **P1（变截面梯度力控）**通过Liang-Rogers仿真验证：力平台比值精确等于截面积比值——纯几何编程，无需电子控制。
- **P2（空间辐向网络）**将任意方向冲击分解为轴向拉伸，八点是三维空间在对称锚固框架下的最小完备配置；其拓扑演化已从二维蜂窝延伸至三维多面体网格，实现了各向同性吸能的构造保证。
- **P3（分级阻尼）**用不同直径丝实现幅值分级阻尼；菱形网编织带将关节旋转分散到数十个节点，使每个节点保持在1–3%弯曲应变内。
- **P4（功能-行程解耦）**将SMA的有限精密行程与系统的大行程需求分离；三环滑动架构发现于震颤护腕的迭代失败中。
- **P5（恒力顺应）**是所有原则的基础——利用超弹性平台在宽应变范围内维持恒力。

五条原则构成力学范式的完整设计空间，与第4章跨域映射表一一对应。温控多级分时变形作为跨域原则，用温度作为时间轴、相变温度作为触发时刻表，是连接力学范式与热学范式的桥梁。后续力学域工程案例章节将以这五条原则为框架，逐一展开力学域元件工程案例，展示每条原则在真实场景中的完整迭代史。
